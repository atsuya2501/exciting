# デイリーダッシュボード

ブラウザで開くだけで使える、毎日の作業用オールインワンダッシュボードです。
インストール・ビルド・サーバー、すべて不要。`index.html` 1ファイルで完結しています。

## 機能

| 機能 | 説明 |
|------|------|
| ✅ 今日のタスク | TODOリスト。チェック・削除・完了済みの一括削除ができます |
| 🍅 ポモドーロ | 作業25分 / 休憩5分 / 長休憩15分。作業終了で自動的に休憩へ切替、今日の完了数もカウント |
| 📅 習慣トラッカー | 週間グリッドで習慣の達成を記録(月曜はじまり) |
| 📝 クイックメモ | 入力すると自動保存されるメモ帳 |

その他:

- 🌙 ダーク / ライトテーマ切替(OSの設定を初期値として使用)
- ⏰ 現在時刻と日付の表示、タイマー作動中はタブタイトルにも残り時間を表示
- 💾 データはすべてブラウザの **localStorage** に保存(外部送信なし)

## 使い方

```
git clone https://github.com/atsuya2501/exciting.git
```

`index.html` をブラウザで開くだけです(ダブルクリックでOK)。

GitHub Pages を有効にすれば、スマホからも URL でアクセスできます:
リポジトリの Settings → Pages → Branch を選んで保存するだけです。

## 注意

- データはブラウザごとの保存です。別のブラウザ・端末とは同期されません。
- ブラウザの履歴・サイトデータを削除するとデータも消えます。
